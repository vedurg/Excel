# 👥 Employee Attrition & Workforce Analytics

### *Turning Employee Data into Meaningful Insights*

**Excel Analytics Project | Data Cleaning · Formula Analysis · Visualization · Dashboard**

---

## 📌 Project Overview

This project transforms employee records into meaningful workforce insights using Microsoft Excel. It explores employee demographics, departmental distribution, salaries, performance, satisfaction, attendance, and attrition through structured analysis and dashboard reporting.

> **Goal:** Turn raw employee data into clear insights that support better workforce understanding and data-driven decisions.

## 🎯 Project Objectives

- 🧹 Clean and prepare employee records for analysis
- 🔎 Explore workforce patterns using Excel formulas
- 🧩 Organize employees by department, role, and location
- 📈 Analyze performance, salary, and attrition trends
- 📊 Build visualizations and an interactive dashboard

## 📊 Dashboard Highlights

The dashboard presents key workforce indicators in a single view:

- **Total Employees**
- **Average Salary**
- **Average Performance Rating**
- **Active Employees**
- **Resigned Employees**
- **Attrition Rate**

Use the department dropdown to explore workforce KPIs for different departments or view the overall organization.

## 🔍 Lookup Demonstration

The `Lookup Demo` sheet makes employee information retrieval easy:

1. Select an Employee ID.
2. Employee details are retrieved automatically.
3. Explore lookup techniques using `VLOOKUP` and `INDEX-MATCH`.

## 🧭 How to Explore

1. Start with `Raw Data` to review the original records.
2. Visit `Cleaned Data` to see the prepared dataset.
3. Explore the `Analysis` sheet for workforce summaries.
4. Try the Employee ID dropdown in `Lookup Demo`.
5. View the charts in `Visualizations`.
6. Open `Dashboard` and change the department filter.

## 📝 Dataset Notes

- Practice dataset created for Excel analytics.
- Original records preserved separately.
- Cleaning and analysis performed in separate worksheets.
- Summary analysis is formula-based, not native PivotTables.
