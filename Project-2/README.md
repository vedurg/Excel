# 📊 Sales Performance & Business Insights Dashboard

**Turning Raw Sales Data into Meaningful Business Insights**

---

## 🚀 Project Overview

This project focuses on analyzing sales data using **Microsoft Excel** to discover valuable business insights, identify high-value customers, track sales performance, and understand profit trends.

The project combines Excel formulas, Data Analysis ToolPak, Pivot Tables, charts, and a dashboard to transform raw data into meaningful information for business decision-making.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify the top 10 customers based on total purchases.
- Perform What-If Analysis using different discount scenarios.
- Understand the relationship between Sales and Profit using Linear Regression.
- Calculate descriptive statistics for Sales, Quantity, and Discount.
- Analyze monthly sales trends and growth.
- Identify high-value customers using INDEX, MATCH, and Filters.
- Summarize key business insights through a Dashboard.

## 🛠️ Tools & Technologies

## 📈 Dashboard Highlights

The Dashboard provides a quick overview of important business metrics:

- 💰 **Total Sales** – Overall revenue generated.
- 📊 **Total Profit** – Total profit earned.
- 🌍 **Region-wise Sales** – Compares sales performance across regions.
- 🥧 **Product Category-wise Sales** – Visualizes sales distribution across product categories.
